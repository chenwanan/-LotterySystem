# 炫酷抽奖系统 Pro（-LotterySystem）

一个开箱即用的前端抽奖系统，适用于年会、活动、课堂互动等场景。

## 功能亮点

- 奖项管理：支持添加多个奖项及名额、动态展示剩余数量。
- 名单管理：支持批量导入参与者（每行一个），自动去重。
- 批量抽取：一次可抽取多人，自动限制在可抽范围内。
- 实时可抽名单：显示剩余可抽人员列表，流程更直观。
- 抽奖动画：滚动闪烁动画 + 彩带特效，增强现场氛围。
- 中奖记录：自动记录中奖时间、奖项与中奖人（支持一次多名）。
- 撤销回退：支持“撤销上一次操作”，避免误操作。
- 数据持久化：使用 `localStorage` 保存数据，刷新页面不丢失。
- 数据导入导出：支持仅导出历史、导出完整备份、导入完整备份。
- 全屏展示：一键进入全屏，适合投屏场景。

## 快速开始

### 方式一：直接双击

1. 下载本项目。
2. 直接打开 `index.html`。

### 方式二：本地静态服务器（推荐）

```bash
python3 -m http.server 8080
```

然后访问：`http://localhost:8080`

## 使用说明

1. 在**奖项配置**中添加奖项名称和数量。
2. 在**参与者名单**中每行输入一个名字并导入。
3. 在**开始抽奖**中选择奖项、设置抽取人数并点击“开始抽取”。
4. 在**抽奖记录**中可撤销上一次抽奖、导出记录或导入/导出完整数据。

## 技术栈

- CSS3（玻璃拟态 + 动画）
- Vanilla JavaScript（无框架依赖）
