# 炫酷抽奖系统（-LotterySystem）

一个开箱即用的前端抽奖系统，适用于年会、活动、课堂互动等场景。

## 功能亮点

- 奖项管理：支持添加多个奖项及名额、动态展示剩余数量。
- 名单管理：支持批量导入参与者（每行一个），自动去重。
- 抽奖动画：滚动闪烁动画 + 彩带特效，增强现场氛围。
- 中奖记录：自动记录中奖时间、奖项与中奖人。
- 数据持久化：使用 `localStorage` 保存数据，刷新页面不丢失。
- 记录导出：一键导出 JSON 抽奖记录。
- 一键重置：快速清空当前活动数据。

## 快速开始

### 方式一：直接双击

1. 下载本项目。
2. 直接打开 `index.html`。

### 方式二：本地静态服务器（推荐）

```bash
python3 -m http.server 8080
```

然后访问：`http://localhost:8080`

## 使用说明

1. 在**奖项配置**中添加奖项名称和数量。
2. 在**参与者名单**中每行输入一个名字并导入。
3. 在**开始抽奖**中选择奖项并点击“开始抽取”。
4. 在**抽奖记录**中导出记录，或活动结束后重置系统。

## 技术栈

- HTML5
- CSS3（玻璃拟态 + 动画）
- Vanilla JavaScript（无框架依赖）
